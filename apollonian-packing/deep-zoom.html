Deep Zoom

The same explorer, rebuilt on arbitrary-precision (Decimal) arithmetic instead of float64, so zooming in doesn't hit a precision wall.

The Standard tab generates each new circle with ordinary JS numbers, which only carry about 15-17 significant decimal digits — deep enough for a lot of zooming, but the position math eventually loses precision and the camera has a hard zoom ceiling to keep it from showing numerical garbage. This page runs the same recursion with a configurable-precision decimal library instead, so the packing stays accurate dozens of orders of magnitude deeper. The tradeoff is speed: decimal arithmetic is much slower than native floats, so density defaults are lower here and circles materialize a bit more lazily while you zoom — this page is built for patient, deliberate exploration of one region, not a dense initial view.

The HUD's zoom readout is the giveaway: watch the exponent climb well past what the standard page can reach before either running out of precision or of your patience.
